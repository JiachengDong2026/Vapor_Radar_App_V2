# 机载三维水汽激光雷达项目的FPGA下位机开发

我正在进行机载三维水汽激光雷达项目的FPGA下位机开发工作，需要完成多个设备的控制、数据采集、数据处理、时间同步以及和上位机之间通信等工作。我是该项目的总体负责人，需要给三个项目成员进行任务分配，并进行整合以及最终调试，另外，也需要和上位机开发人员进行对接。

## 0 大项目背景和本子项目任务目标

### 0.1 大项目背景

完成基于TDLAS-WMS技术的机载原位水汽检测+机载水汽遥测传感器的开发，用于大气三维水汽廓线测量。目前系统的硬件、机械、光学等部分基本完成，我负责的子项目是完成该项目的FPGA下位机开发。项目涉及到多个传感器设备，包括2个激光驱动器、2个光电探测器、1个气压计、1个温湿度传感器、1个GNSS、2个MEMS器件（温湿度）。需要实现对每个传感器设备的控制与通信（有些不需要控制，只需要采集数据即可），数据的采集与解调，多传感器设备的时间同步，与上位机的通信（接收上位机指令、整合所有数据发送给上位机等）。

### 0.2 本子任务目标

- 【目标1】对两个激光驱动器进行控制：1）原位测量系统和遥测系统各使用一个 DAC；2）两个 DAC 均输出本系统的 WMS 组合信号（低频锯齿波+高频正弦波），不按高速/低速模式划分；3）两套系统的锯齿波和正弦波频率均可通过上位机独立调节；4）两个 DAC 分别控制对应系统的激光驱动器（每个ADC单独控制一个激光驱动器，本项目中不用考虑低速和高速ADC的区别）。
- 【目标2】ADC采集两个探测器输出的信号，两个ADC的采样率可以通过上位机进行控制（每个ADC单独对探测器的信号进行采集，不用考虑高速和低速问题）
- 【目标3】设计一个正交锁相放大器对信号进行解调：1）通过上位机对DILA内部参数进行设置；2）输出解调得到的一次谐波和二次谐波；3）可调参数包括但不限于：解调基频、参考相位、输出采样率；4）低通滤波器采用巴特沃斯，滤波器暂时使用固定参数
- 【目标4】接收气压计、温湿度计、GNSS、2个MEMS、电机、温控、测距雷达等设备的控制与通信
- 【目标5】给所有传感器数据加上时间戳，用于数据的时间同步。ADC的原始数据不需要时间戳，但ADC采集的每个周期（即每一个WMS锯齿波扫描周期）的数据需要加一个时间戳（每个周期代表一个点的浓度，因此是一个周期加一个时间戳）。
- 【目标6】使用usb3.1接口和上位机进行通信
- 【目标7】设计一套完整的通信与控制协议，用于与上位机之间的通信（包括各模块的参数设置、控制、数据传输等）

### 0.3 我负责的工作

- 负责整个下位机的统筹、任务分配、整合以及最终调试等工作
- 共有三个成员参与下位机的开发，DILA、USB、指令/协议编解码、同步时钟生成、模块集成等工作由我来完成，其余的模块分配给他们来完成（每个传感器、ADC和DAC的控制都作为一个单独的模块）
- 他们完成并测试通过后，将文件代码、测试结果、说明文档等内容交付给我，由我最终对这些模块进行整合，开展最终联调
