# VLP1 下位机能力扩展与上位机交接（2026-10-17）

需求依据是同级 VaporView 的 `docs/fpga_ui_capabilities.md` 中“当前 VLP1 功能缺失”、AI8 八通道自动轮询与可变 DLIA 低通清单。基线为 `0f12988`。本次只改下位机仓库；VaporView/SkyCore 尚需按本契约适配，不能直接解除旧 UI 的禁用状态。

VLP1 的帧版本、CRC32、source 0040..0047、旧寄存器、默认单通道 schema 2 和默认 1 kHz 数值结果保持兼容。所有新增操作通过已有 CRC 校验后的 `READ_REG` / `WRITE_REG` 实现；写寄存器的 RESP 只确认 FPGA 接收，不代表外部设备执行成功。不得在结果未知时自动重发写操作。

`GET_CAPABILITIES` 最后一个扩展能力 word 从 `0x01` 扩展为 `0x3F`：bit0 RAW schema 2；bit1 AI8 扫描/schema 3；bit2 AI8 参数事务；bit3 EPSILON MAIN 下行邮箱/RTCM；bit4 独立 RD105；bit5 DLIA 截止频率档位。旧模块 ID 保留；新增能力必须查能力位，不可从旧 ID 推断。生产状态轮询增加最后一个 slot：page 68/source 0048；之前 21 个 slot 的序号保持原样。

## AI8 自动八通道扫描

source `0046`、page `6600`、ID `00460200`。`6668 SCAN_ENABLE` 为 0/1，只能在 AI8 禁用时配置，默认 0。0 保留 `661C` 指定通道和 schema 2；1 按 1..8 扫描，每个通道完成全部七次 FC03 后发一条 schema 3 记录，新增 U32 TLV `0468`（通道 1..8），其余 tag、单位不变。`662C` 是一整轮扫描结束后的间隔；实际刷新周期还包含八路串口事务时间，不能把配置值当成实际每通道频率。

失败也产生带该通道号、online=0、设备错误与异常码、ERROR flag 的记录；失败通道不会复制另一通道的数据。`6698 CACHE_CHANNEL` 选择 1..8；缓存只用于诊断历史快照，是否当前有效还需检查 CONTROL 和时间戳：

| 地址 | 含义 |
|---|---|
| 66A0 | bit0 在线、bit1 曾收到结果、bits5:2 Modbus 错误、bits13:6 异常码；复位为 0 |
| 66A4 | 低 16 位 PV、高 16 位 SP，原始 0.1 °C 有符号值 |
| 66A8 | 低 16 位 OP、高 16 位 SV |
| 66AC | 低 8 位报警、次 8 位控制状态、高 16 位主机状态 |
| 66B0/66B4 | 本通道最近一次结果的 64 位 tick，低字在前 |
| 66FC | feature bits0..3=扫描、通道 TLV、参数事务、写后读回 |

设温仍使用 `6620` 微摄氏度或 `6650` 原始值和原有 COMMIT / SENSOR_ACTION 17。新增 `666C SET_CHANNEL` 允许在运行时指定目标 1..8，0 沿用 `661C`。COMMIT 时锁存目标通道，扫描游标不会影响设温地址；待确认时禁止改目标。`6648` 仍只在仪表写 ACK 和独立 SP 读回一致后增长。

## AI8 通道、PID、组和全局参数

按 AI-8 手册 V9.6 第 7 节的真实 Modbus 地址逐寄存器执行；通道参数用 base+channel-1，输入/输出组用对应组地址，全局参数用 0840..085F。FPGA 不转换参数单位，沿用手册和上位机已有参数编解码。

| 地址 | 含义 |
|---|---|
| 6680 | 写 1=FC03，2=FC10 后 FC03 核验；写 3 返回 `ERR_UNSUPPORTED=13` |
| 6684 | 仪表 16 位寄存器地址 |
| 6688 | 写入的 16 位原始值 |
| 668C | bit17 结果有效、bit16 pending、bits15:8 异常码、bits7:4 Modbus 错误、bits3:0 结果 |
| 6690 | 实际读回值，不以请求值冒充 |
| 6694 | 完成或取消计数；提交前保存基线，完成后须增长 |

结果：0 完成/读回一致；1 写失败；2 读回失败；3 读回不一致；5 禁用取消。传输错误沿用 Modbus master：1 超时、2 CRC、3 地址/功能/长度、4 设备异常、5 UART/帧间隔、6 配置错误。参数事务与轮询、设温串行，完整事务中不插入轮询；新参数写和读回均不自动重发。事务期间禁止修改地址、数据和再次提交。禁用时不接收新事务。

允许读取 0000..04DF、0600..06EF、0800..085F；测量/状态、主机状态、型号及序列号只读。具体子型号不支持的地址由仪表异常明确反馈。写 Addr/bAud/AFC 可能改变通信条件，旧链路下的核验可能超时，此时结果未知，不能提示成功或自动重试；应按设备实际参数重新连接。

**AI8 恢复出厂仍不支持。** 仓库的 AI-8 手册列出 FC03/06/10 和参数锁，但没有恢复出厂命令。`Loc` 位是写保护，不是恢复出厂。没有厂家补充契约前不伪造复位指令或默认值表；FPGA 模块软复位也不等同于仪表恢复出厂。

## EPSILON MAIN 参数命令和 RTCM

source `0042`，新增 `6240..6270` 邮箱，默认通过现有 MAIN RS232 的物理 TX 发送；另有显式选择的独立 RS422 RTCM 输出。FPGA 原有 FDILink 接收、导航/观测上传不变。邮箱先保留 UART，自动恢复探测不能插入其中；恢复命令尚在执行时提交返回 BUSY。天地侧仍复用原 USB/VLP1；不会另开天地链路。

| 地址 | 含义 |
|---|---|
| 6240 | 写 1 提交；尚未完整装载、禁用、忙或参数非法则拒绝 |
| 6244 | 实际字节数 1..1029；写入会清空 staging 计数 |
| 6248 | 0=ASCII 命令，1=完整 RTCM3 帧 |
| 624C | bit17 result_valid、bit16 busy、低 8 位结果 |
| 6250 | 物理发送完成的累计字节数 |
| 6254/6258 | 传输完成/失败次数（不代表设备参数已生效） |
| 625C | 实际响应字节数 0..2048 |
| 6260/6264 | 响应 byte offset（4 字节对齐）/只读 4 字节，低字节先 |
| 6268 | 连续写入 TX staging，低字节先，每次完整 32 位；最后一字补 0 |
| 626C | 当前已装载 word 数 |
| 6270 | ASCII 响应超时 100..10000 ms，默认 2000 |
| 6274 | 0=MAIN（默认）；1=独立 FPGA_RS422_TXD_L correction 输出，仅允许 RTCM |
| 6278 | correction UART 波特率，默认 115200，9600..SYS_CLK_HZ/16，须与实体口匹配 |
| 627C | 实际发完的原始 RTCM 字节数，独立于 FDILink 包装开销 |

流程：设置 KIND/LENGTH，重复写 TX_DATA 共 ceil(length/4) 次，读回 LOADED，保存 6254/6258 基线，START，等待 busy 清除和有效结果。busy 时不能覆盖 staging 或改 baud，也不能软复位模块；普通禁用会完成正在发送的整帧后报告取消。硬复位、失电和线路断开不能保证对端收到完整帧。

ASCII 必须为 `#` 开始、LF 结束的完整 MAIN 命令行。上位机按 EPSILON 手册和已有命令生成器显式执行进入配置、包频率/安装杆臂/融合/GNSS/DGNSS/校准/重启等命令及查询、退出配置；邮箱不自行修改命令、进入配置或执行额外动作。响应从 `#` 或 `*` 开始缓存，静默 50 ms 后完成，最多 2048 字节；超限明确报错，不把截断结果当成成功。参数写后需再发查询并解析实际响应；`#ERROR` 同样是原始响应，邮箱的结果 0 只说明响应已收取，不能当成设备成功 ACK。命令导致重启/无应答时须保留未知结果，重连核对。

RTCM staging 可通过多条 VLP WRITE_REG 装载，但在整帧完成前不会发送任何字节。FPGA 检查 D3、保留位、10 位长度（最大 payload 1023）及 CRC24Q；错误整帧拒绝。默认 MAIN 目标按 EPSILON 手册 11.2.32 / 厂家 2026-01 MCU/ROS 例程的 `MSG_RTCM_CORRECTIONS=0x73` 包装：每片最多 255 字节，连续序号、头 CRC8、payload CRC16（高字节先）和 FC/FD 标志；最大帧拆为 255/255/255/255/9 共五片，原始 RTCM 重组后逐字节不变。不可把裸 D3 流直接发给 MAIN。

独立目标 1 则通过板上既有 `FPGA_RS422_TXD_L` 发送裸 RTCM，需实际接到 EPSILON 上可配置为 RTCM 的空闲输入口，匹配 RS422 电平和波特率，并按手册表 21 确认该口的协议；禁止把内部 GNSS 保留口改为 RTCM。未接线/未配置时不能宣称这个目标有效。两种目标都必须实板确认接收器固件的支持情况。

一次接收完整 6..1029 字节；busy 覆盖整帧全部片段，不接受下一帧和 ASCII 插入。结果 0 只代表全部 UART 停止位发送完成，不证明 EPSILON 已解析/应用差分。6250 计物理 UART 字节（含 FDILink 开销），627C 计原始 RTCM 字节，6254 计完成事务；断线或电气失败需依赖接收器状态和现场验收，UART 无法凭空提供对端应用 ACK。

邮箱结果：0 传输/响应完成，1 应答超时，2 应答超限，3 RTCM CRC，4 禁用取消，7 格式。校验失败不会改变物理发送计数，也不会自动重试。

## 独立 RD105

source `0048`、page `6800`、ID `00480103`，不再是 AI8 的别名。生产连接复用 CON19 RS485：HMP/AI8/RD105 三方按完整事务轮转仲裁。**需先将实体 RD105 配置为 19200 8N1、地址 2**；这与其默认 RS485 9600/地址 1 不同，FPGA 不能凭改 UART 寄存器替设备改波特率。HMP 默认地址 240、AI8 默认地址 1。现场必须确认多点接线、终端和唯一地址，不能把空闲 RS422 接口当成兼容的 RD105 接口。

旧 RD105 驱动的字段迁到 68 页：CONTROL/STATUS/ERROR=6804/08/0C；UART/address/通道=6810/14/1C；目标微摄氏度=6820；实际微摄氏度=6824；设备错误=6828；轮询 ms=682C；实际目标=6840；帧计数=6844；设温核验计数=6848。支持通道 1/2，实体单位 0.00001 °C 转换到主机微摄氏度，异常哨兵和错误 flag 保留。消息为 source 0048、1100 schema 1，使用 TARGET_TEMP_UC/ACTUAL_TEMP_UC/DEVICE_ERROR TLV；通道由 681C 的禁用态配置确定。

设温 CONTROL=5 或 SENSOR_ACTION 18（value 为微摄氏度）在 FC10 ACK 后再 FC03 对照目标；一致才更新 6840/6848。独立 source 的 COMMIT、START/STOP、RESET/CLEAR 已接入动作控制器。历史广播 mask 保持旧含义，新增 RD105 必须显式使用 source 0048、mask bit8；全局广播不悄然启用新设备。

完整参数（PID、传感器模型、输出、全局等）按 RD105 v1.3.0 的真实寄存器地址和数量操作：

| 地址 | 含义 |
|---|---|
| 6880 | 写 1=FC03，2=FC10+读回；3=显式 write-only 恢复出厂 |
| 6884/6888 | 仪表起始寄存器 / 数量 1..16 |
| 688C/6890 | 结果状态 / 完成计数，位布局及结果 0/1/2/3/5 同 AI8 |
| 68C0..68DC | 32 字节 TX 数据（串口字节顺序，低字节先） |
| 68E0..68FC | 32 字节实际 RX 数据 |

多寄存器写后逐字节对比全部读回，不自动重发。恢复出厂仅允许手册的 address=0000、quantity=1、wire value=0001（TX word 低 16 位为 0100）并显式写 opcode 3；普通写 opcode 2 不允许地址 0。设备 ACK 后报告结果 **6=已收到写 ACK、最终状态未核验**，停用轮询，必须重连按出厂参数核对，不能将只写命令伪装成可读回成功。未 ACK 则仍为超时/异常，不宣称已恢复。

## DLIA 低通截止频率

5000/5100 两路新增 `+58 CUTOFF_SHADOW` 和只读 `+5C CUTOFF_ACTIVE`，支持 100/250/500/1000/2000/5000/10000 Hz，默认 1000。沿用原 COMMIT，在停用时或新 capture cycle 边界、流水线排空后原子切换；改变截止频率会清除两级滤波历史，不能混用两套系数。旁路仍由 MODE.bit2 决定。

每路是原有四阶 Butterworth，两节 Q2.46 biquad；1 kHz 系数和舍入保持原样。配置档位按编译时 INPUT_RATE_HZ（1 MHz / 12.5 MHz）生成；非默认截止频率仅允许在实际输入率等于该标称率时 COMMIT，否则范围拒绝，不能将标称 Hz 冒充其它采样率下的截止频率。ADC0/1 的共享采样时序未拆分。

生成器 `fpga/scripts/generate_lpf_coefficients.py` 使用 SciPy；已提交 RTL 表，运行/综合不依赖 SciPy。`test_lpf_profiles.py` 检查 14 种采样率/截止频率组合的量化极点稳定性、精确 DC 增益及截止点约 -3.0103 dB；RTL 回归另检查周期边界提交与默认数值精度。
