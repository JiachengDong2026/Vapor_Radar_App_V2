# Qt 上位机源码开发交接（V0.2.5）

日期：2026-10-11。正式源码入口：[host/qt_monitor](../../host/qt_monitor/README.md)。来源为 2026-10-09 的 WMS 电压版测试工程；本次不改变 FPGA、FX3 或 USB 线协议。

## 1. 推荐阅读顺序

1. [设备与寄存器对接](HOST_HANDOFF_20261001.md)：设备版本、命令/数据来源、启动顺序；其中路径和板测结论有历史日期，最新下位机同步见 [10月4日记录](../MERGE_MANIFEST_20261004.md)。
2. [VLP 协议](FPGA_HOST_PROTOCOL_V1.0.md)：40字节帧头、小端字段、CRC、命令应答。
3. `host/qt_monitor/src/protocol.cpp`：实际数据解析与分片重组；`worker.cpp`：异步控制顺序。
4. [BIN 存储格式](BIN_STORAGE_FORMAT_V1.0.md)：录制、回放、RAW、谐波及传感器字段。

## 2. 架构与线程

```text
FX3 USB（04B4:00F1，OUT 02 / IN 86）
  ↕ CyUSB
VaporUsbBridge.exe（C#）
  → stdout 原始 USB 字节 → Worker → VlpParser → DataDecoder → UI/TracePlot
  ← 本机带会话令牌的 TCP 命令通道 ← Worker 命令队列
```

桥接 stderr 为状态/错误，stdout 仅为原始流。Worker 位于工作线程，界面通过信号/槽提交操作并接收快照。USB 始终只有一个 IN 接收者，等待命令应答时也持续解析数据。一次 USB 返回不等于一帧；CRC、序列、source/msg、分片及完整周期检查不可省略。

`protocol.h/.cpp`、`worker.h/.cpp`、`bridge/VaporUsbBridge.cs` 是正式开发复用的核心；可以替换界面而保留这些层的边界。内部 JSON 约定见 [contract.md](../../host/qt_monitor/src/contract.md)。

## 3. 控制语义

- 打开程序及连接设备不会自动启用 WMS。采集、WMS、DLIA 可独立控制，但完整 RAW/DLIA 周期帧依赖对应 WMS 扫描边界。
- “应用并启用”提交 WMS 编辑值；“启动扫描”使用设备已有配置。软件显式序列化禁用、提交、启用、延迟和读回，不将一次 WRITE 成功当整个配置生效。
- WMS 界面单位为标称峰值 V，输入除以 10 后进入 worker 的归一化参数；**不要在 worker 再除以 10**。设备寄存器仍为 Q1.31。
- WMS 停止时 DAC 保持末值，不能把按钮文字改成“归零”。断开连接保留 WMS/DAC 输出；重新下载 FPGA 或掉电是另一种情况。
- DLIA 支持参考源、参考频率、H1/H2 相位、输出率、分片点数、滤波旁路等参数。四阶版本低通固定 1 kHz，当前没有可调截止频率接口。
- 命令超时可能意味着写入已经发生，不能无条件重发；必须核对设备状态和错误路径。

## 4. 数据含义及板卡约束

- 六传感器保留新鲜度、报警、输入有效性和断线信息，旧值不能伪装成新样本。PTB210 超时、AI8 设备报警没有通过源码同步自动解决。
- ADC 原码有符号24位。当前 GUI 默认前端增益0.5、参考5 V、CON15正向/CON16负向电压还原，绑定已拆 RLY5 并飞线的板卡；软件的增益选项只改变换算，不切换硬件电阻。
- EPSILON 无定位或 UTC 未同步时不能把零经纬度当有效定位。
- H1/H2 和每周期 H2 峰值目前是数字幅值 code；尚未包含光程、谱线、浓度标定，不能直接标成 ppm。
- 绘图只对显示做降采样并保留极值；缺片/无效数据保持断线。固定纵轴、滚轮缩放不改变记录数据。
- BIN 是 Bulk IN 原始字节流，无私有文件头；不是只保存曲线点，也不完整保存所有外部接线、激光器设置及用户控制历史。正式版建议另存会话元数据，避免回放时误用电压比例。

## 5. 同步与验证边界

保留 V0.2.5 功能源码；工程化调整包括外部构建输出、显式 CyUSB 依赖路径、CTest 离线入口、历史采集文件改为命令行参数，以及清理旧开发合同中的过期约束。源代码单元测试入库，生成的 EXE/DLL、图像、日志、采集数据、比特流均不入库。

本轮执行正式路径的构建、离线测试和既有历史数据解码，不连接板卡、不改变正在运行的激光器/WMS。验证结果见 [本次同步记录](../QT_HOST_SYNC_20261011.md)。后续正式产品仍需针对实际硬件、断连恢复、持续采集和打包环境完成实机验收。
