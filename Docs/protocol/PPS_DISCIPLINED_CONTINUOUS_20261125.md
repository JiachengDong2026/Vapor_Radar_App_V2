# PPS 校正的双路 100 Hz 连续扫描

本版合并 `6503190` 的启动观测与 DLIA 参考流水，以及 `0bfb750` 的组帧丢点恢复。WMS 每路新增可选模式 2，用于两路 100 Hz 锯齿连续扫描。DAC 仍使用原更新率与原正弦调制参数，DLIA 按实际扫描周期分帧并保留滤波历史。

## 配置与读回

1. 两路停机并排空，分别读取 `0x208C`、`0x218C`，返回 `0x50504301` 表示支持本接口。旧固件按原接口处理。
2. 在禁用状态将两路锯齿频率配置为 `100000 mHz`，两路采用相同的 DAC 更新率与传输时序。沿用现有幅度、偏置及调制频率，提交后核对生效配置。配置两路 ADC、DLIA，选择 WMS 参考。建议 `EXPECTED_PER_CYCLE=0`，因为微调周期时物理采样点数会随实际时钟关系变化。
3. 启用 TIME、设置 PPS 沿。两个通道都在停机状态写 `0x204C=2`、`0x214C=2` 并回读。在原有两路 START_ACQ 流程中启用采集并持续接收。等待阶段沿用各通道的 `IDLE_LEVEL`，其含义是 DAC 有符号码。
4. 两路均选择模式 2 时，首次启动等待两路均就绪后的同一个合格 PPS。只有一路选择模式 2 时可独立启动。运行中的一路继续输出，即使另一通道随后停机。
5. `+0x90` 的 bit0 表示已经起扫，bit1 表示 TIME 当前 PPS 合格。`+0x94` 是每个 DAC 更新的实际锯齿相位增量，一整圈为 2³²。`+0x58` 统计接收的 PPS，`+0x60/+0x64/+0x68` 给出最近接受的 PPS 序号和 tick。每个扫描周期用 WMS `cycle_id` 和 DLIA 帧判定。单次扫描的 `ACTUAL_START/END`、`COMPLETED_COUNT` 以及 CON11-12/14/16 的窗口启动脉冲沿用模式 1 语义。观察模式 2 的整秒边界可用 CON22 与 CON7/CON8。

## 校正与失锁保持

每对相邻、合格且在标称一秒 ±1% 内的 PPS 提供一个实测秒长。控制器根据该间隔计算每次 DAC 更新的正向锯齿相位步长，同时按最近采样相位校正距整秒最近的扫描边界。相位反馈每秒最多消化四分之一个扫描周期。为了将边界稳定放在 PPS 之后，校正目标预留约两个 DAC 更新间隔的采样余量（受上限约束）。整秒处正在输出的锯齿继续自然走到回扫，DAC 采样节拍和正弦相位连续。闭环稳定时目标是每个 PPS 间隔 100 个完整周期。捕获与恢复的过渡期间，单个 PPS 间隔的边界计数可能变化。

丢失 PPS 时沿用最近的有效步长。恢复后的第一条合格沿重新建立时间基准，取得相邻有效间隔后平滑校正。主机停机、复位或传输故障使该通道退出跟踪，重新启动时等待合格 PPS。两路物理输出边沿的偏差包含 DAC 数字写入及模拟建立时间，需用示波器测量。
