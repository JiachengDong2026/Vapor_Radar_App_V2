# 2026-09-28 双低速 ADC 集成修订

> 历史记录保留：本文中的DLIA `00020101`属于2026-09-28二阶构建，不回写旧BIT的版本或板测证据。2026-10-02隔离候选源码已升级到模块`0101`、四阶1kHz profile`00040101`（双路1MHz）；当前算法说明见[DLIA精度修订](INTEGRATION_REVISION_20261002_DLIA_PRECISION.md)。双AD4630硬件与采样接口规则仍适用。

本修订根据用户要求，将尚未由厂家调通的高速 ADC3660 输入替换为同板 AD4630-24 的另一物理通道。正式顶层默认 `DUAL_AD4630=1`。它优先于旧指南、任务书及2026-09-23修订中 ADC1=ADC3660/CON17 的描述；历史路径保留为参数0，仅用于兼容回归。

## 输入与数据接口

| 逻辑通道 | 模拟输入 | ADC物理通道/数据lane | 寄存器页 | USB source | 格式 |
|---|---|---|---|---|---|
| ADC0 / DLIA0 | CON15 SMA | AD4630 IN0± / SDO0..3 | 4000 / 5000 | 0020 / 0030 | 24位二补码、符号扩展到32位 |
| ADC1 / DLIA1 | **CON16 SMA** | AD4630 IN1± / SDO4..7 | 4100 / 5100 | 0021 / 0031 | **24位二补码、符号扩展到32位** |

将原CON17信号线移至CON16。两路独立模拟输入、独立FIFO/错误/样本计数、独立DLIA，**共用同一个AD4630的CNV、SCK和采样频率**，并非复制ADC0数据。SDO0/4首先提供bit23，SDO1/5为bit22，SDO2/6为bit21，SDO3/7为bit20；每个SCK收4bit，共6拍24bit。MODES=80，四lane、SDR、24bit。

共同默认1,000,000 S/s，当前采集实现允许1,000～1,000,000 S/s，不能独立配置两路频率。每次共同CNV同时保存两路各自WMS周期/相位和统一采样timestamp；各路可独立启停。ADC3660驱动从默认硬件网表去除，时钟静止、片选不活动、RST保持有效。

## 寄存器兼容与变化

- `4000=00200101`、`4100=00210101` 标识共享AD4630模式，旧版是末字节00。source ID与VLP版本不变。
- ADC0 `4010`仍是请求采样率、`4014`实际率；`4030/4034`为CNV高电平ticks/BUSY超时。通过ADC0提交共同采样时序。
- ADC1 `4110/4114`均**只读共同实际采样率**。写4110不再接受旧12.5MS/s配置，返回只读错误。
- 两路 `+18`格式均`00011800`。RAW payload的`adc_bits`均24；上位机必须读取元数据，不能根据source0021硬编码16位。
- ADC1 `4130/4134`只读共同CNV ticks/BUSY timeout；`4138=80`为MODES。原高速ADC的lane/DCLK/sync-count含义不再适用，`4140`未映射。对ADC1整页读取最多到413C，不能沿用旧17字(含4140)批读。
- 两路CONTROL、ERROR W1C、独立expected-per-cycle、FIFO/drop/sample-count、RAW enable保留。
- ADC0 reset/commit时要求两ADC均disabled且物理转换空闲；否则返回busy。ADC0 reset重新初始化共享芯片。ADC1 reset只清本路状态/FIFO，不复位共享PHY；不会停止另一通道。
- 共同时序提交pending时，拒绝任一路启动。停用/清FIFO取消该路在途结果，不影响另一通道。
- DLIA1 `INPUT_RATE_HZ`与默认滤波profile改用1MHz，`5124=00020101`，默认10kHz输出抽取100；`5150=100`，不再1250。与DLIA0一样解调1f/2f。
- 低通系数是固定构建profile；改变共同采样率不会自动设计新滤波器，截止频率随采样率变化。推荐本轮保持1MS/s。

## 推荐配置顺序

1. 停止ADC0/1；等待物理BUSY空闲与两路capture/fanout排空，再停DLIA0/1并排空输出。必要时清队列。
2. ADC0软件复位(4004=2)会复位共享芯片，等初始化完成后设置4010=1000000、401C=0，提交4004=4，等待pending清零。ADC1需要时仅做4104=2清本路；不要写4110。
3. 读取4014/4114核对两路1MS/s、4018/4118均24bit。
4. 配置两路DLIA参考20,000,000mHz、相位0、输出10000Hz、MODE2，并各自commit；读取504C/514C=10000、5050/5150=100、5024/5124=00020101。
5. 先启动DLIA0/1，再启动ADC0/1；需要RAW时设置403C/413C及raw stream mask高字bit0/1。即使只测试ADC1也需先配置共同时序。
6. 改共同采样率后必须重新提交两路DLIA，更新其抽取和参考计算。旧FIFO数据必须在改rate前排空，防止旧数据被新rate解释。
7. 收尾只停止ADC/DLIA/RAW及传感器，保留WMS/DAC；整体重烧bit会短暂停止所有输出，重烧后需重新配置启动。

现有FX3的VLP透明传输无需修改。旧主机测脚本需改ADC1读写地址、24bit量程与1MHz采样率。USB整体格式和既有六传感器/DAC接口不变。
