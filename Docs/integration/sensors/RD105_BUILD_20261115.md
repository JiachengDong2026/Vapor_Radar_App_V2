## 验证范围

`tb_rd105_uart` 使用独立位级三设备 BFM：CRC、站号、异常、超时、RTU静默/DE、仲裁持有与公平进度；两个通道自动轮询、负温度与int64占空比换算、无效实际温度省略TLV；目标写ACK后FC03确认、仅ACK/读回不符不算成功、读回传输失败、非幂等写不自动重发、32字节缓冲读写顺序、参数结果/计数/取消、保护整段跨区间写、FIFO整条丢弃与背压、复位/禁用。+40仅保存确认设温，不随另一通道轮询变化。

顶层黄金命令扩展为88条，分别在HMP和默认HC2A顶层模式检查6A身份/默认值、LC0/LC1身份、源页隔离、禁用时提交拒绝、SENSOR_ACTION17与不支持动作、无意外UART写。decoder/action独立回归验证AUTO_COMMIT及确认计数。

旧断言只按真实接口修正：能力0x29更新为0x3B；AI8已有scan +68/+6C及feature +FC=11的读/写权限同步。未撤回既有AI8扩展，未修改VaporView。

## 构建追踪

第一轮`rd105_full_20261115_a`因最终动作回归发现AUTO_COMMIT掩码遗漏而主动终止；第二轮`rd105_full_20261115_b`在源码复核发现新仲裁器宽度常量使用Verilog-2005的`$clog2`后终止。已换为Verilog-2001本地常量函数，并加入静态检查防止回归。两轮build_result保持pass=false、无BIT。最终使用全新`rd105_full_20261115_c`，不复用a/b轮或任何历史综合/实现检查点。`source_inputs.json`与`full_build/build_inputs.json`封存输入哈希，BIT写出前再核对输入。

仿真原始失败轮保留：早期声明顺序/首轮禁用commit验证修正；旧黄金能力/AI8断言已同步；新AUTO_COMMIT用例暴露并修复掩码。最终结果以最新同名用例及最终构建签核为准，失败轮不改写为通过。
