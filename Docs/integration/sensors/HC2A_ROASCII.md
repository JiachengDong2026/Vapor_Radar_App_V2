# HC2A 正式接口与接线说明（2026-11-13）

本版已从 `hc2a_gpio_20261028_01/rh_case_fix_01/repo` 合入正式 V2，保留双路激光 UART、PPS 时间校准、DM422、电机窗口与 AI8 既有逻辑。发布身份及验证范围见[最新说明](../../LOWER_COMPUTER_RELEASE_20261113.md)。

## 接线方案：CON11 通用 IO，保留 TFA1500

本版取代先前 CON19 转换器候选和 CON21 替换 TFA1500 的方案。HC2A 独占两根 Bank88 GPIO，由 FPGA 内部 UART 以 19200 / 8N1 进行 RO-ASCII 请求/应答。**TFA1500 继续使用 CON21 及原低频输入；AI8 继续使用 CON19。**

| HC2A 针号 | 信号 | 连接 |
|---:|---|---|
| 1 | VDD | 外部独立稳压 **3.3 V** 正极 |
| 2 | GND | 外部电源负极，并接板卡 GND，例如 **CON21 pin4** 或 CON19 pin3 |
| 3 | RXD，探头输入 | **CON11 pin13**，GPIO_BANK88_LP7，FPGA AK13，HC2A_UART_TXD |
| 4 | TXD，探头输出 | **CON11 pin15**，GPIO_BANK88_LN7，FPGA AL13，HC2A_UART_RXD |
| 5 | OUT1 湿度模拟输出 | 本数字接法不接 |
| 6 | OUT2 温度模拟输出 | 本数字接法不接 |
| 7 | AGND 模拟地 | 本数字接法不接，不能替代 pin2 数字地 |

两根 IO 均为 **LVCMOS33**，不使用 Bank89 的可变 VADJ，也不需要 RS-485 转换器。LP/LN 是原理图网络名，本版将它们作为两个独立单端 GPIO 使用。CON11 不含 GND，也不提供探头电源；不要将 CON11 pin12、14 等信号脚误当电源或地。CON21 pin3 是 EN 信号，不是电源。

针号按手册第 7 页“面对探头 7 针公头”的视角确认，线缆母头视角会镜像。手册没有线色表，应按针号和导通关系确认，不沿用 HMP 棕/蓝/黑/白颜色。**禁止向 HC2A 或 GPIO 接入 HMP 原来的 24 V。** 手册允许探头 3.3–5 V，本版固定使用 3.3 V 供电以匹配 UART；GPIO 不容许直接接 5 V TTL 或 RS-232 电平。

原理图第 7、34 页与当前管脚分配核对：新增 pin13/15 不与 I2C、BMP390、TFA 低频、两路激光 UART、电机冲突。此前预留的 pin13/15 在本版中改为 HC2A；其余设备管脚不变。板上原 CON21 外侧 UART 为 3.3 V，内部经 SN74AXC8T245 连接 1.8 V FPGA Bank64，保留其原约束。

## 下位机行为

- 顶层 `HC2A_ENABLE=1`（正式版默认）选择 HC2A；`HC2A_ENABLE=0` 可构建原 HMP 版本，此时新增 GPIO TX 保持高电平。两者互斥，HC2A 占原 HMP lane 1，AI8 仍占 lane 6。
- HC2A 主动发送 `{FxxRDD}\r`，接收 19 个分号字段、校验单字符 checksum 后提取相对湿度和摄氏温度。检查数字探头类型、%RH 或 %rh/摄氏单位、字段范围、UART 帧错误、地址、帧长度；拒绝无效测量占位符、过长数字、错误单位及校验失败的数据。
- 默认每次成功或最终失败后等待 1000 ms 再开始下一轮，响应超时 600 ms，失败重试 1 次。实际记录间隔还包含串口请求/响应与解析处理时间；不能把 1000 ms 理解为严格 1 Hz。
- HC2A 只使用 CON11 的独立 UART，不参与 CON19 仲裁。AI8 可以在 HC2A 等待应答、超时或重试时继续轮询。TFA1500 两路接收与命令发送均保留，不与 HC2A 的 TX/RX 相连。
- 不发送 REN、HCA 或探头参数写命令，不会改变探头地址、协议或标定。需要探头保持 RO-ASCII 请求/应答模式，关闭 HW4 的 unsolicited 自动上报模式。
- 采样时间戳在响应首个 UART 起始位采集，同时锁存 time_sync_valid；继续使用整机现有 PPS 校准时间基准。这不是探头内部测量时刻。

## 地址设置

顶层参数 `HC2A_DEFAULT_ADDRESS=99`。99 是手册定义的临时未知地址查询，不是厂家默认地址。上电后首次发 `{F99RDD}\r`，有效回复会携带实际地址；下位机校验后学习该地址，之后只查询该地址。它不会写探头的非易失配置。

**只有一台 Rotronic 探头时才使用 99 发现。** 若有多台 RO-ASCII 设备，先通过 HW4 核实地址，禁用 lane 1 后把实际地址 0..64 写入 0x6114，或修改构建参数。AI8 默认 Modbus 地址仍为 1。

## 上位机接口

source_id 继续用 0x0041，page 继续用 0x6100，ID_VERSION 为 **0x00410106**。记录 msg_id=0x1100、schema=1，使用原 HMP 的 RH tag 0x0100 和温度 tag 0x0101（F32），device error tag 0x0002 携带 Rotronic 报警字节。常规曲线解码可复用，界面设备名称应区分 HC2A。

**HMP 压力补偿/COMMIT 不适用于 HC2A。** 0x6134 现在是只读报警字节，CONTROL.bit2 和 SENSOR_ACTION 16 的压力写入会被拒绝。不要对 HC2A 套用 HMP 的地址 240、8N2、压力补偿启动流程。连接时应识别新版 ID，再使用本页配置。

| 地址 | 权限 | 含义 |
|---:|---|---|
| 0x6100 | R | ID_VERSION=0x00410106 |
| 0x6104 | R/W | bit0 启用；bit1 软件复位；bit3 清 FIFO；bit2 不支持 |
| 0x6108 | R | 在线、事务状态、FIFO/错误状态 |
| 0x610C | R/W1C | sticky ERROR：bit0 超时、bit1 checksum、bit2 丢记录、bit4 配置错误、bit6 探头报警、bit7 格式错误 |
| 0x6110 | 禁用时 R/W | 波特率，默认19200；允许1200..115200且不超过SYS_CLK_HZ/16 |
| 0x6114 | 禁用时 R/W | 已知地址 0..64；99 发现；有效发现后更新为实际地址 |
| 0x6118 | 禁用时 R/W | 固定 0=8N1；仅允许写 0 |
| 0x611C | 禁用时 R/W | 轮询等待间隔 100..3600000 ms，默认 1000 |
| 0x6120 | 禁用时 R/W | bit0 RH、bit1 温度，至少选择一项 |
| 0x6124 / 0x6128 | R | 最新 RH（%）/温度（°C）F32；失败时保留上次值，须同时看 online/计数 |
| 0x612C / 0x6130 | R | checksum 错误次数 / 超时次数 |
| 0x6134 | R | 最新成功记录的 Rotronic 报警字节 |
| 0x6138 / 0x613C | R | FIFO level / drop count |
| 0x6140 | R | 最近解析报警：bit9 温度、bit8 RH、bit7..0 设备报警 |
| 0x6144 / 0x6148 | R | 成功记录数 / 格式错误次数 |

F32 由小数值经 Q16 转换，在接受的 -100..600°C 范围内转换误差小于 0.0001（低于当前两位 ASCII 小数的分辨率）；不是逐位相同的主机浮点四舍五入结果。设备报警时可上传数值并置记录 flags.bit4；无效响应不生成正常测量记录。ERROR 为历史粘滞状态，故障恢复后仍需显式 W1C 清除；不要据其单个位判断当前是否在线。

建议调试顺序：读 0x6100 确认版本 → 禁用（0x6104=0）→ 核对地址/19200/8N1/间隔 → 启用（0x6104=1）→ 观察 0x6108 online、0x6144 递增及 0x6124/28 数值，再启用 AI8 检查双设备进展。初次排障可先只启用 HC2A。

## HCD2 诊断寄存器

当前 0x614C 只读返回 **0x48434432**（HCD2）。0x6150 为 UART 接收字节计数，0x6154 为 UART 错误计数，0x6158 为最近完整应答描述，0x615C 为最近失败原因位图；0x6160..0x61FC 为最多160字节的原始应答快照。读取多字寄存器前先禁用采集以保证快照一致。详细位定义沿用[诊断扩展](../HC2A_DIAGNOSTIC_20261028.md)，其中HCD1为修正前历史签名。
