# 简易 DM422 控制窗口（2026-11-10）

双击 `host/start_motor_panel.cmd`，或运行 `python host/motor_panel.py`。使用 Python 3 和 tkinter，依赖现有 Cypress 驱动、VaporUsbBridge.exe 及其同目录 CyUSB.dll。可在窗口中选择桥接程序。先关闭占用 FX3 的其他上位机。

1. 点击“连接 / 检查”，核对固件、电机禁用状态和错误。连接和刷新只读，不会下载或运动。
2. 默认 40 脉冲、100 Hz，点击一次“上移 ＋（接入方向）”或“下移 −（移出方向）”运行一次。忙时禁止追加动作。
3. 若小位移难以观察，可在确认机械余量后选择 400 脉冲。仅在 1600 脉冲/转、4 mm 导程条件下对应约 1 mm。方向依据下述当前装配记录。
4. 结束自动禁用电机并关闭本次启用的全局控制；日志中必须看到禁用确认。脉冲累计只是 FPGA 计数，不是编码器位置，没有自动回零。
5. “停止 / 禁用”取消待执行操作，并通过串行 USB 操作禁用电机。禁用可能截断当前脉冲；不是硬件急停，最坏响应受正在等待的 USB 应答和清理操作影响。通信断开时不能保证读回禁用成功，应使用现场断电措施。FPGA 另有 2 秒主机心跳看门狗。

窗口关闭时请求禁用并等待工作线程结束。运动中的心跳取决于窗口持续响应，不运行独立永久心跳线程；界面超过 1 秒未更新时停止继续动作并尝试禁用。USB 延迟可能超过文档建议的 250 ms 心跳间隔，日志记录每次动作的最大发送间隔；不据此宣称完成失联工况验收。

每次运动前检查 MOTOR/TIME ID、固定极性和时序参数、全局控制及其他模块全部禁用。单次 1～400 脉冲、20～400 Hz，与现有固件一致。MOVE 应答丢失不重发；失败后需显式重新连接，绝不重放动作。清除电机错误只在禁用空闲时允许，不清软件位置或系统错误。

本工具不刷 Flash、不重配置 FPGA，不控制激光或传感器。板卡断电后需另行恢复当前整机 SRAM 比特流。系统错误显示原值，不能把“电机错误=0”理解为整机无错误。

日志在 `%LOCALAPPDATA%/VaporMotorPanel/logs/`。`--check` 执行只读硬件验证后退出。单元测试：`python -m unittest discover -s host -p test_motor_panel.py`。

版本记录：2026-11-10 新增手动窗口及取消/通信失败测试，未改变 RTL、硬件管脚或寄存器协议。接口依据 `GNSS_PPS_DM422_20261027.md`。

## 45°反射镜方向记录（2026-11-10）

电机带动45°反射镜上下移动：向上接入光路，向下移出光路。用户在本次 +2000 脉冲（理论5mm）试动后明确确认有明显位移，且镜子向上移动。因此当前装配的正脉冲 / DIR=0 对应上移、接入方向；负脉冲 / DIR=1 对应相反的下移、移出方向，后者尚未在本次装配上单独实测。

窗口标签表示运动方向，不表示已完全接入或完全移出。两端位置、所需总行程和实际5mm距离尚未标定，无到位反馈；不能将软件累计脉冲当作镜子绝对位置。历史旧装配的“正向缩回”描述不用于推断当前光路方向。更改接线或安装后需重新确认。
